# Prompt 01 – Foundation: ERAD primitives and app shell

Read AGENTS.md, DESIGN.md and src/styles/tokens.css first. Do not start with a plan; this one is a build. Do not touch the backend yet.

Build the ERAD foundation for a desktop enterprise app.

1. Import `src/styles/tokens.css` once at the root. Map Tailwind theme values to the CSS variables (colors, spacing, radii, fonts) so utilities resolve to tokens. Load "Ericsson Hilda" with the fallback stack in tokens (do not fetch fonts from a mirror). Theme switch: `data-theme="light|dark"` on `<html>`, default light, a toggle in the system header.
2. Create primitives in `src/components/erad/`, restyled to DESIGN.md (not default shadcn look). Each has all states in DESIGN.md (idle, hover, press, focus-visible, disabled, error where it applies):
   Button (default, primary, icon-only with aria-label; AI variants with the gradient), TextField (label, helper, error with aria-describedby/aria-invalid, prefix/suffix), Select/Dropdown (36px trigger, menu with 32px items, group headers), Checkbox, Radio, Tag (status tones with colour + word + 16px icon; small tag), Pill (filter chip, removable), Tooltip (hover and focus, Escape closes), Table (header 48px, rows 48px, hover/selected/striped, sortable header, row checkbox, trailing row actions on hover and focus), Card, SidePanel (356px, collapsible to 80px, 16px padding, 1px border outside), Dialog (572px, 24px padding, no scrim, actions right: default then primary), Tabs (tab navigation items 80x58 and a simple text tab bar), Toast/notification (elevation 1), Divider, Breadcrumb, EmptyState (icon, title, cause, action), Spinner, Skeleton.
3. App shell: 48px system header on `layer-system` (product name "Documents", a permanent tag "Prototype · synthetic data only", tenant name, theme toggle, user menu), 240px left navigation on `layer-application` (Documents, Search, Admin; 40px items with selected state). After sign-in the app lands on Documents with the entity list. Hide "Search" until prompt 09 builds it (a dead link costs people time). **Reflow for zoom (WCAG 1.4.10):** below 1280 CSS px wide (for example 1440 at 200 % zoom) the navigation collapses to 80px and side panels overlay the content instead of squeezing it; this divergence is already recorded in DESIGN.md "Divergências registradas" (decided 2026-11-06), content on `layer-content` with 16px horizontal padding, page header row 32px (title left, actions right). Shell max width 1920, centred.
4. A `/design` route showing every primitive and state side by side (light and dark) for review. This route is dev-only.
5. Components the product needs that DESIGN.md does not define, built from tokens and listed in `docs/decisions/01-foundation-gaps.md` with the reason (never edit DESIGN.md): a text tab bar (32px row, Label 14, 2px `border-item-selected` indicator; the ERAD tab-nav item is 80×58 with a caption and cannot hold "Documents 10 · 2 need attention"); a destructive Button (primary shape, fill `status-critical`, text `text-on-primary`); a progress bar (4px, `fill-item-selected` on `border-item-subtle`); an inline banner (Card with a status tag at the left); a skeleton row; an avatar (24px circle, initials). Unavailable controls everywhere use `aria-disabled` plus a visible reason, never the native `disabled` with a tooltip (a disabled control cannot be focused, so the reason is unreachable). Dark theme: the 1px `#8e45b0` focus ring is about 2.6:1 on `#242424`; add a token `border-focus-dark` at a lighter purple that reaches 3:1 and record it as a divergence.

Constraints: only tokens, spacing steps 1/2/4/8/12/16/24/32, status never colour alone, `prefers-reduced-motion` respected, keyboard operable with the purple 1px focus ring at 2px offset. Do not add libraries other than those already in the project.

Done when: `/design` renders at 1440 and 1920 in light and dark with no console errors; tabbing through every primitive shows the focus ring; no hex literal exists outside tokens.css. Report in one line what you checked, naming elements.
