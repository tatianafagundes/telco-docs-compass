# Multi-perspective review of the prototype as the rebuild's oracle (2026-11-12)

Target: `tatianafagundes/telco-docs-compass` at `main` `8cd46ff`, reviewed on branch `review/multi-perspective-2026-11`. The prototype (TanStack Start + React 19 + Supabase) is the behavioural oracle for the Angular/Java rebuild: `docs/rebuild/00-README.md` says "when this pack and the app disagree, the app's tests decide". This review asks where that oracle is wrong, so the rebuild does not copy the error, and fixes only what the rebuild inherits: spec documents, tests, the traceability CSV, review ADRs and the internal OpenAPI contract in the working folder. The React UI code was not reformatted, refactored or touched (`src/components/ui` included).

Verdicts: **BLOQUEIA** = the rebuild would inherit a tenant or data leak, an invariant break, or a design that cannot serve the operator scenario. **CORRIGIR** = wrong but contained, or underspecified. **NOTA** = observation. Each finding names the file and line in the repository and the rule or invariant it contradicts (`BR-xxx` from `docs/rebuild/03-business-rules.md`, invariant `Inv-n` from `17-kiro-steering/invariants.md`, `L1`–`L6` from `04-security-and-tenancy.md`, `Never` from the kit's `AGENTS.md`).
